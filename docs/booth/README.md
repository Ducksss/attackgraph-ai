# Booth materials

Made for the AttackGraph AI booth at AWS AI Fest 2026, Singapore, on 15 October 2026. Figures in them, such as the test count, are as of that date.

| File | What it is |
|---|---|
| [`booth-slideshow.pptx`](booth-slideshow.pptx) | An 11-slide explainer for the booth screen: the problem, the route a one-line change opens, the four steps, Amazon Bedrock's role, the verified fix and how it is built. It fades between slides and loops on its own, about two minutes a cycle, and a click still advances it. Each slide has talking points in its speaker notes. |
| [`architecture-a4.pdf`](architecture-a4.pdf) | A one-page A4 handout: the route the flagship change opens, how the prototype works, and the result of the fix. |

To present the slideshow by hand instead of on a loop, choose Slide Show, then Set Up Slide Show, then Manually. It uses Arial and the colours in the [brand kit](../brand/README.md), so it looks the same on any machine with PowerPoint or Keynote.
